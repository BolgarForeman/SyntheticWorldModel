## The rule (Foreman, 2026-10-22)

No parameter is set without a stated reason. Every rule in the world must assert at least one part of **Curtin's three-part test** (GY618) for why it is set the way it is:

1. **Someone else defined it.** A standard, regulation, published method or measured record sets the value. A software default, or a value carried over unexamined, does not count.
2. **There is a good reason.** A substantive argument tied to the process that produces the quantity: its physics, its scale, its operating practice, or a data property.
3. **A robust sweep.** If neither settles it, run the value across a range and report whether the conclusion holds, and where and why it flips.

Then, as in Curtin's write-up step, the rule names the value, the test or tests that justify it, and **the limitation the choice leaves**.

The three are reasons, not tiers. A rule may assert more than one. None outranks another: a sweep shows how much the answer depends on a value, not whether the value is right.

## The work this sets

1. **Registry fields** (a registry pull request, decision 0021):
   - `justification`: one or more of `defined_by_others`, `good_reason` or `robust_sweep`, each with its text, source or sweep result;
   - `limitation`: one line;
   - `review`: by, date, and an outcome of accept, change or sweep.

   CI fails any rule with no justification, and the Modeling Rules page renders the axes. The current grade (S, L, J) stays in the registry's history, mapped to the new field and checked by hand, not by script.
2. **The code's choices:** each `# CHOICE:` comment and each unrecorded engine convention gets a registry entry, or a line in the code that points to one.
3. **The influence screen,** a tool outside the generator's build path. Each rule with a range or a relaxed value is swung to its ends, one at a time, on the pilot world. It measures the change in:
   - the 8 reference storm runs;
   - calm-world criticality;
   - the default-order restorative run.

   No full answer-key search. The output is a ranked table, written beside the register.
4. **Families re-cut by method,** with the screen's high-influence rows moved to the decisions list. The first review pass then runs from the top of the ranked list.

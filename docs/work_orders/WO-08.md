WORK ORDER 8 — Emission, truth manifest, hand-trace pack

Branch: wo8/emission. It already exists on GitHub, holding:

- World_Generator_Structure.md at v0.10 (§4.6 and §4.8 rewritten; §4.5 refill rate);

Build on it. One pull request into main.

Why: the world exists only inside the generator. The pipeline ingests files. This work order writes the world out as the real sources would: one OpenStreetMap extract, the WRI plant database, OurAirports, and the government facility register. Beside them go the truth manifest that says what is really there, and the printable pack the pilot's hand trace is done on. Phase 1 emits with zero error; Phase 3 corrupts these files.

Spec: World_Generator_Structure.md v0.10 §4.1a, §4.6, §4.8; Emission Ruling Sheet v0.2 (E1–E8); Pilot_Spec.md v0.7; CLAUDE.md (§3 separation, §4 byte identity, §9 synthetic identifiers and no real data); decisions 0001–0014, and 0015 below. The spec is the authority.

PART 0 — REFILL RATE (from PR 16)

0.1 Water stocks that refill from the main (purified boiler water, make-up water, hospital water) refill at the rate they drained. Add the registry rule `reserves.main_refill_rate_fraction`:
- default 1.0;
- range 0.5–1.0 (0.5 takes twice as long);
- relaxed value: instant refill;
- grade J, ruled 2026-10-10.

The engine reads it. Add a test at each end of the range and at the relaxed value.

PART A — OPENSTREETMAP (E1–E4, E6)

A1 One extract for the island: `sources/osm/island.osm.pbf`, plus `island.osm` (XML) beside it.
- It holds every switched-on OpenStreetMap source's features, each limited to its scope (SOURCE_SCOPES).
- Fixed timestamp, version 1, one synthetic user and changeset.
- Ids from 9,000,000,000,000, assigned in sorted order of the world's own ids.

A2 Tags follow the OpenStreetMap wiki for each class. Your CHOICE, reported as a table with the wiki page for each:
- power=plant (plant:source, plant:output:electricity), power=substation (substation, voltage), power=line (voltage, circuits, cables), power=tower;
- telecom exchanges, masts, data centres, cable landings;
- water works, reservoirs, pumping stations, storage;
- ports (use the tag families the MCIN_Pipeline ports check finds on Taiwan's ports), aerodromes, freight yards, roads (highway=*), bridges;
- fuel sites;
- hospitals, clinics, blood banks.

Carry the attributes the real tags carry, scored and context, and no others.

A3 Outlines (E2):
- Area classes (plants, substations, hospitals, water works, reservoirs, ports, airports, tank farms, refineries) become closed ways. Each is a rectangle centred on the true location.
- Footprint sizes by class are registry placeholders (J), drawn per node on its own stream.
- Point classes are nodes.
- Power lines are ways through their tower nodes.
- Within-layer links on emitted layers that are not node-only are ways (pipeline, water main, communication line).
- Node-only layers emit no links. Couplings and feeds are never emitted.

A4 Names (E4):
- Town names come from a fixed list of soft syllables in the registry: plain, pronounceable, invented, two or three syllables (for example "Corvan", "Telmar", "Brenna Point").
- Every urban area gets one name, drawn on its own stream.
- Facilities are named by town and class in each source's style. OpenStreetMap uses short names ("Corvan Substation").
- A share of masts, pumping stations and distribution substations is left unnamed: registry placeholder 20% (J).
- English only.
- A test screens every generated name against a short list of common English words and well-known world place names, kept in the test code.

A5 Identity:
- The PBF must be byte-identical on Windows and Linux.
- zlib output can differ between zlib builds, so if your writer compresses, write the PBF blobs uncompressed (raw), which the PBF format allows.
- State which you did. pyosmium (BSD-2) or a small writer of your own are both acceptable.
- Confirm the file opens in osmium, GDAL/ogr and QGIS.

PART B — WRI, OURAIRPORTS, FACILITY REGISTER (E3–E6)

B1 Each file copies the real file's column header, in order, as the pipeline ingests it.
- Record each header in code with its source and version: WRI GPPD v1.3 `global_power_plant_database.csv`; OurAirports `airports.csv` at the date the pipeline landed it; the facility register the pipeline landed (Chapter 6, H5).
- Check each once locally against the real file through machine.toml, and report the check. No real data enters the repository; a header is schema, not data.
- Emit only columns the real file has.

B2 WRI (`sources/wri_gppd/global_power_plant_database.csv`):
- generation nodes only;
- country `XSW`, country_long "Synthetic World";
- `gppd_idnr` `XSW0000001…`;
- capacity, primary fuel and commissioning year from the world, other columns empty as the real file leaves them;
- formal plant names ("Telmar Thermal Power Station").

B3 OurAirports (`sources/ourairports/airports.csv`):
- airports only;
- `ident` `XS-0001…`;
- no ICAO, IATA or GPS codes;
- `iso_country` `XS`, `iso_region` `XS-01…` by district;
- type from the world (towered → medium_airport, else small_airport: your CHOICE, stated);
- scheduled service from the world.

B4 Facility register (`sources/facility_register/…`):
- healthcare classes;
- register-style institution codes with an `XS` prefix;
- formal names;
- register level;
- beds where the real register carries them;
- latitude and longitude in place of the address (E5, declared departure).
- If the real register carries no bed count, report it and leave beds out (the scored list then drops beds for this source).

B5 Coordinates are WGS 84 at 7 decimals (§4.1a).
- CSVs are UTF-8 with `\n` line endings, sorted by id, with fixed float formatting.

PART C — TRUTH MANIFEST (E7)

C1 `truth/manifest.yaml`, apart from `sources/`. It holds everything in spec §4.8:
- **Cross-source correspondence:** every true element and its id in each file.
- **True geometry:** each location; each outline's corners and centre; each line's route and tower points; each feed's road route.
- **Every unobserved value** with its target and levers.
- **Hidden layers and couplings.**
- **Scored and context lists** per source.
- **Declared departures:**
  - coordinates in the register;
  - English-only names;
  - rectangular footprints;
  - uncompressed PBF blobs, if used.
- **θ\*:** the registry fingerprint and the Theta List.
- **Seeds and spawn tree.**
- **Planted errors:** an empty list, marked "zero-error emission (Phase 1)".

C2 The GeoPackage inspection export gains layers for true footprints, true routes and towers, and feed routes.

C3 A test proves that no source file contains any value that appears only in the manifest (feeds, couplings, unobserved values, world-internal ids).

PART D — HAND-TRACE PACK (E8)

`swm trace-pack [--scenario N]`, scenario 7 by default, writes to `trace_pack/`.

D1 **The map.** A one-page PDF map showing:
- nodes with ids and class symbols;
- lines and towers;
- within-layer links;
- the seven switched-on couplings as arrows;
- the crew base;
- the scenario's track;
- the damaged elements.

D2 **Tables**, as PDF pages and as CSV:
- nodes, with class, requirement, stocks and hours, and failure mode per commodity;
- dependencies, with supplier, consumer, commodity, κ and transfer form;
- the scenario's damage list, with gust or flood depth and the repair needed;
- the reference run's timeline, hour by hour, with crew jobs. It must match the saved reference run exactly.

D3 **Identity.**
- The PDF must be byte-identical on both platforms. Use a fixed creation date and producer.
- Turn off PDF stream compression for the same zlib reason as A5, or show that it is identical.

PART E — COMMAND, SEPARATION, RECORDS

E1 `swm build` writes a world's full output tree:
- the resolved recipe;
- `sources/`;
- `truth/`;
- `trace_pack/`.

`swm emit` writes `sources/` alone.

E2 **Separation.** Emission code receives only observed quantities (CLAUDE.md §3). Extend the separation test to every writer: none may import unobserved fields, the dynamics, or error induction.

E3 **Records.**
- `docs/decisions/0015-emission.md`: the E1–E8 rulings and the refill rule;
- the CHANGELOG;
- a TRACE note.

TESTS
- Identity: every file under `sources/`, `truth/` and `trace_pack/` is byte-identical on both platforms, and the goldens are checked in.
- OpenStreetMap:
  - every emitted feature is in its source's scope;
  - node-only layers have no ways;
  - outlines are closed and centred on the true location within rounding;
  - every line passes through its towers in order;
  - ids are ≥ 9e12, unique, and sorted.
- Identifiers: no ICAO or IATA codes; every country field is XS or XSW.
- Names: deterministic; screened; the unnamed share within rounding of 20% on the 10-node world.
- Headers match the recorded real headers exactly.
- Correspondence: every emitted record maps to exactly one true element, and every true element in a source's scope appears in it (zero error).
- Separation, as E2 and C3.
- Hand trace: the timeline table equals the saved reference run for scenario 7.

Out of scope:
- error induction (Phase 3);
- bilingual names;
- addresses and a gazetteer (Phase 6);
- the World Port Index, OpenInfraMap, healthsites.io, submarine cables and the LNG and dam registers (not switched on in the pilot). Build the writer pattern so they can be added, but don't write them.

Report in CLAUDE.md §11 format, including:
- the tag table;
- the four recorded headers and the local check against the real files;
- the file tree for the pilot with sizes;
- a screenshot of the pilot extract in QGIS;
- the hand-trace map;
- every golden change.
